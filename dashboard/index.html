TOKEN RADAR

radar-3 model · calibrated on this snapshot

Protocols that record no token yet, ranked by what a token would be worth if their record stayed as it is. The value is not a guess and not 30% of TVL: it is fitted from the snapshot itself. Every protocol in this snapshot that already has a token teaches the model what a token is worth at a given TVL — log(market cap) = A + B·log(TVL), fitted by least squares — then each category gets its own shrunk factor from the same fit. A big TVL earns a smaller multiple, a small one a bigger multiple, because that is what the market data says. Growth moves the value at most 15% and age at most 10%: a 7-day window and age barely predict the multiple, so they are kept small on purpose. Tokens that already trade live on a separate view — never mixed into the ranking.
