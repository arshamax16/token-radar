How to read this board: rank 1 is the highest implied value. The implied range is the honest part — half of similar protocols' true values fall inside it, so a $65M point with a $14M–$174M range is a $65M guess, not a $65M fact. Token odds are the chance a token ever launches, from the peers' own record: the category's token rate times how much of the launch window the protocol's age has already used up. The verdict is a rule, not a feeling — FARM means implied value ≥ $20M and 7-day change ≥ −10%, THIN means implied value ≥ $5M and 7-day change ≥ −25%, anything else is SKIP. Every row carries a 7-step farm plan built from that protocol's own TVL, chains, category and age, with what each step costs and how long it takes; the top 20 also state what an hour of farming costs in gas. Open a row to see exactly how its implied value, its range and its odds were computed. Nothing here predicts whether or when a token launches.
